CI methods 備忘

不用背；查什麼、選什麼、怎麼解讀。

必學概念

  • 95% 是選的覆蓋率，不是資料算出來的。正確說法：重複抽樣下，約 95% 的區間會涵蓋真值。
  • TPR 的分母是 Pass 範例；TNR 的分母是 Fail 範例。分母小，CI 就寬。
  • 4/4 不等於 100%；Wilson 95% CI 約 [0.51, 1.00]。
  • Wald 在 n 小或 p 接近 0／1 時會壞；改用 Wilson、Clopper-Pearson 或 bootstrap。
  • Bootstrap：重抽樣、算統計量、取百分位。不需要常態假設。
  • 回報 point estimate + CI，不要只報單點。
  • 寬度：單一比例約 1/sqrt(n)；corrected rate 約 1/(J*sqrt(n))。

選哪個方法

方法什麼時候用弱點
Waldn 大、p 不靠近 0／1小樣本與極端值會壞
Wilson小樣本、p 靠近 0／1仍是近似
Clopper-Pearson要保守、小樣本區間較寬
Bootstrap任何統計量，例如 corrected rate需要寫程式；結果依重抽樣

規則：n < 30 或 p 接近 0／1，不要用 Wald。

公式查表

Wald

p_hat ± z * sqrt(p_hat(1 - p_hat) / n)

Wilson

p  = 觀測比例
n  = 樣本數
z  = 1.96（95%）

center = (p + z^2/(2n)) / (1 + z^2/n)
half   = z * sqrt(p(1-p)/n + z^2/(4n^2)) / (1 + z^2/n)
CI     = center ± half

z 值

90%: 1.645
95%: 1.960
99%: 2.576

Bootstrap

for i in 1..B:
    sample = resample(data, replace=True)
    stat[i] = statistic(sample)

CI = [percentile(stat, 2.5), percentile(stat, 97.5)]

Rogan-Gladen

J      = TPR + TNR - 1
theta  = (p_obs + TNR - 1) / J
Var(theta) ≈ Var(p_obs) / J^2

工作例：4 個 Fail

觀察TNR約 95% Wilson CI
4/41.00[0.51, 1.00]
3/40.75[0.30, 0.95]
45/500.90[0.78, 0.96]
50/501.00[0.93, 1.00]

4 個 Fail 只要錯 1 個，TNR 就掉 25 個百分點；這就是為什麼要 ~50／50。
