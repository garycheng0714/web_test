# 定案：產品回到自動化管線，蘇格拉底式教練降級為「學習方法」

使用者一度把「蘇格拉底式教練」當成產品本身（Q14–Q23）。經拷問後定案為**讀法 A**：

- **產品**＝QA 自動化 agent（讀 PRD → 產測試項目 → 產自動化測試 → 自動修復）。
- **「蘇格拉底式教練」＝ OpenCode 對「使用者」的學習方法**，不是產品功能。
- 「技能保留」的對象是使用者這個**建造者**，不是 agent 的終端使用者。
- **專案目的**＝學會「把領域導入 agent」；QA 是練習載體，可帶走的是經驗 ＋ 範本 repo。

影響：
- `learn/MISSION.md` 改寫成新目的。
- `.scratch/prd-to-tests/spec.md` 的 Problem/Solution 重新框架（產品＋學習方法兩層）。
- 先前 Q22「v1 先不要自動化」作廢；自動化回到產品範圍。
