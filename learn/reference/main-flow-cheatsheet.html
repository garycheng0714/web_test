主流程速查

貼在牆上的一頁。搭配第一課 0001-the-main-flow。

1. idea → ship 主流程

idea │ ▼ grill-with-docs ── 訪談收斂，順手寫 CONTEXT.md / ADR │ ├─ 問題非得「跑起來看」才知道？ ─► handoff → prototype → handoff │ ▼ 多 session 的大工作？ ├─ 是 → to-spec → to-tickets →（每票 fresh context）implement └─ 否 → implement（同一 context） │ └─ 內部驅動 tdd（紅→綠）→ code-review → commit

2. 三條 on-ramp

情境Skill要點
別人丟來的 issue / 外部 PR 堆積triage把 raw 的東西變成 agent-ready；不要 triage 由 to-tickets 產生的票
東西壞了 / 效能退化diagnosing-bugs先逼出「已對此 bug 變紅的 tight feedback loop」，再修，最後補回歸測試
大到一個 session 裝不下、方向模糊wayfinder用決策票地圖推霧；霧散才接回 to-spec

3. Codebase 保養

improve-codebase-architecture 掃出 deepening 機會 → 挑一個生成 idea → 回主流程 grill-with-docs。

4. 誰能觸發（很重要）

類型觸發方式Skills
User-invoked只有你打（/to-spec）；負責編排流程ask-matt, grill-with-docs, grill-me, to-spec, to-tickets, implement, triage, wayfinder, improve-codebase-architecture, handoff, teach, retro, setup-*
Model-invoked你或 agent 都可；承載可重用的紀律tdd, codebase-design, domain-modeling, diagnosing-bugs, code-review, writing-for-agents, research, prototype, pr, grilling

規則：user-invoked 可以呼叫 model-invoked，但不會呼叫另一個 user-invoked。

5. 五個先記住的詞

tracer bullet窄但打穿每一層的垂直切片，單獨可驗證，塞得進一個 context。
seam你測試與觀察行為的公開邊界；測試只立在事先講好的 seam。
deep module小介面、厚實作；deep module 的詞彙來自 codebase-design。
smart zonesession 前期模型仍銳利的區間（約 100–150k tokens），之後漸入 dumb zone。
paper trailgrill-with-docs 邊談邊留下的 CONTEXT.md / ADR，讓後續 spec 與票同語言。
