Coder 由哪些 capability 疊成

把 Coder() 拆成它內部的每一顆 capability；標出哪些是私有、公開替代是什麼。供日後查或手動重組時對照。

一句話

Coder 是一個 CombinedCapability：把檔案、命令、repo 脈絡、委派、context 管理、輸出上限、參數修復疊起來，再加它自己的預設指示。怎麼裝上去，就能怎麼拆下來。

來源：pydantic_ai_harness/coder/_capability.py（harness 0.54.0）

組成一覽（依序）

#Capability關鍵設定公開？

私有項 → 公開替代

私有手動重組時的替代
RequireWorkspace('Coder')可略過（只要你永遠掛 LocalWorkspace）；否則自行在 run 起頭檢查 workspace
INSTRUCTIONS / project_instructions寫你自己的指示；或在 Agent(instructions=...) 補上「investigate → implement → verify、依 repo 慣例、跑測試」等重點
_BoundToolOutputsToolOutputLimits(bands=[Band(over=64_000, action=Truncate(max_chars=64_000))])；注意公開版可能多掛一個 spill 檢索工具，屬差異

Coder 預設指示在做什麼（摘要）

INSTRUCTIONS（coder/_instructions.py）要點：用工具去 investigate／implement／verify；讀既有碼、依 repo 慣例；修因不修果；務實套用 DRY/YAGNI/SOLID/Zen；自主做到完、只在缺需求/憑證/不可逆動作時才問；跑聚焦測試、回報**實際**驗證了什麼；只留要求的變更、別留 scratch 檔。另加 project_instructions 點名工作目錄。

手動重組骨架（公開 API）

from pydantic_ai import Agent
from pydantic_ai.capabilities import LocalWorkspace
from pydantic_ai_harness.coder import FILE_TOOL_NAMES
from pydantic_ai_harness.compaction import ClearToolResults, WarnNearLimits
from pydantic_ai_harness.filesystem import FileSystem
from pydantic_ai_harness.repair_tool_arguments import RepairToolArguments
from pydantic_ai_harness.repo_context import RepoContext
from pydantic_ai_harness.shell import Shell
from pydantic_ai_harness.subagents import SubAgents
from pydantic_ai_harness.tool_output_limits import Band, ToolOutputLimits, Truncate

CODING_CAPABILITIES = [
    FileSystem(content_hashes=False, max_read_chars=50_000, tools=FILE_TOOL_NAMES, max_retries=5),
    Shell(denied_commands=[], default_timeout=270, allow_interactive=True, tools=["shell"]),
    RepoContext(expose_inventory_tool=False),
    SubAgents(include_self=True),
    ClearToolResults(max_fraction=0.7),
    WarnNearLimits(max_context_fraction=0.9),
    ToolOutputLimits(bands=[Band(over=64_000, action=Truncate(max_chars=64_000))]),
    RepairToolArguments(),
]

agent = Agent(
    model,
    capabilities=[LocalWorkspace(workspace_dir), *CODING_CAPABILITIES],
)

要點：SubAgents(include_self=True) 必須以 Agent(capabilities=[...]) 綁定（不能用 run() 傳入）；FileSystem／Shell 在 run 的 workspace 工作，沒有 workspace 會失敗。

版本提醒

Harness 為 0.x；上表的私有路徑（coder._capability、coder._instructions、_workspace）與常數值可能隨 minor 版變動。手動重組請以公開 API 為主，私有項僅作對照。
