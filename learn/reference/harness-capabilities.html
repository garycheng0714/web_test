Harness capabilities 速查

課 0003 的壓縮版。忘記某個 capability 屬於哪一類、或 Skills 怎麼設，回來看這頁。

一句話

pydantic-ai-harness 是官方 capability／harness 庫；每個東西都是一個 capability，丟進 capabilities=[...]。核心 Pydantic AI 供「需要模型或框架支援」者，其餘 30+ 個在 harness。

能力分群

群代表 capability做什麼
Harnesses（整套）Coder、Researcher現成完整 stack，本身是多個 capability 的組合，可拆
執行環境FileSystem、Shell、Modal／E2B／Sprites sandbox、SSHWorkspaceagent 動手的檔案與命令，本機或隔離沙箱
工具與原生能力MCP、Image Generation、GitHub、Linear、Notion、Slack接外部系統與 provider 原生工具
Web 與研究Web Search／Fetch、Exa、You.com、Browser Use、Playwright上網找、讀、跑真實瀏覽器
推理／規劃／委派Thinking、Planning、SubAgents、DynamicWorkflow、Advisor、BackgroundTools怎麼想、怎麼分派工作

完整清單與連結見 官方 Capabilities 表。

progressive disclosure（按需載入）

capability 標 defer_loading=True 且給穩定 id ▼ 初始 prompt 只含 catalog：deferred capability 的 id（＋description） ▼ 有 deferred capability → 框架自動加 load_capability 工具 ▼ 模型呼叫 load_capability(id) → 該 capability 的 instructions／tools 才生效

判斷準則：大部分回合用不到的，就不要 eager 載入。少數 coherent 的 bundle 勝過一堆碎 capability。

Skills 設定速查

from pydantic_ai import Agent
from pydantic_ai.workspaces import LocalWorkspaceBackend
from pydantic_ai_harness import Skills

agent = Agent(
    "google:gemini-2.5-flash-lite",
    capabilities=[
        Skills(
            ".agents/libraries/test_case_designer",  # library 目錄，非單一 skill
            include=["qa-test-case-generation"],      # 或 exclude=...，不可同時
            workspace=LocalWorkspaceBackend("."),     # 必需，否則 run 起頭就失敗
        )
    ],
)
設定catalog 內容
兩者都省略所有掃到的 skill
include=['a','b']只有 a 與 b
include=[]沒有 skill
exclude=['a','b']除 a、b 以外的全部
  • 掃描直接子目錄；skill/references/SKILL.md 不算新 skill。
  • 只載 SKILL.md；不列舉／讀取／執行 references/、assets/、scripts/。
  • name 可省略（用資料夾名）；description 必填、非空，出現在初始 catalog。
  • 多個 library 可並存；選中的名字必須唯一。
  • include／exclude 只控制 catalog 曝光，非權限邊界。

版本政策（重要）

Harness 用 0.x 版號：API 可能在 minor 版之間變動（改名、改預設、重構），會有 deprecation 警告與遷移說明；patch 不刻意破壞。這是「獨立成套件」換來的演進速度，不代表不成熟。
