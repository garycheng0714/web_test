# Test Case 6: Contact Us Form

## Test Steps

| Step | Action | Expected Result |
| --- | --- | --- |
| 1 | Launch the browser. | The browser is launched successfully. |
| 2 | Navigate to `http://automationexercise.com`. | The home page is loaded. |
| 3 | Verify that the home page is visible successfully. | The home page is displayed correctly. |
| 4 | Click the **Contact Us** button. | The Contact Us page is opened. |
| 5 | Verify that **GET IN TOUCH** is visible. | The heading is displayed. |
| 6 | Enter name, email, subject, and message. | All form fields contain the provided values. |
| 7 | Upload a file. | The selected file is attached to the form. |
| 8 | Click the **Submit** button. | The form is submitted and a confirmation dialog appears if required. |
| 9 | Click the **OK** button. | The confirmation dialog is dismissed. |
| 10 | Verify that the success message is visible: `Success! Your details have been submitted successfully.` | The success message is displayed. |
| 11 | Click the **Home** button. | The application navigates to the home page. |
| 12 | Verify that the home page is displayed successfully. | The home page is visible. |
